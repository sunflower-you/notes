# 安装
官方文档：安装 — OpenCompass 0.3.3 文档



## 创建环境
目录结构：
opencompass/
├── configs
├── data            # 解压后的数据集
│   ├── gsm8k       # gsm8k数据集
│   ├── mmlu        # mmlu数据集
├── ...
├── docs            # 文档
├── human-eval      # human-eval 
├── opencompass     # 每次评测，以日期前缀命名
│   ├── cli         # 
│   ├── configs     # 每次实验都会在此处存下用于追溯的 config
│   ├── datasets    # 运行日志
│   │   ├── eval
│   │   └── infer
│   ├── metrics     # 储存了每个任务的推理结果
│   ├── models      # 每个数据集不同类别的评测结果
│   └── summarizers # 评测结果
├── run.py        # 程序入口
├── ...


### 1、 从头开始安装(optional)
1. conda环境安装
```
conda create --name opencompass python=3.10 -y
conda activate opencompass
```
2. OpenCompass工程安装
```
git clone https://github.com/open-compass/opencompass opencompass
cd opencompass
pip install -e .
```

3. human-eval安装
opencompass工程添加submodules，安装
```
cd opencompass
git clone --recurse-submodules git@github.com:open-compass/human-eval.git
cd human-eval
pip install -e .
pip install -e evalplus
```

### 3、数据集配置
1. 下载github数据集(optional)
```
wget https://github.com/open-compass/opencompass/releases/download/0.2.2.rc1/OpenCompassData-complete-20240207.zip
unzip OpenCompassData-complete-20240207.zip
cd ./data
find . -name "*.zip" -exec unzip "{}" \;
```

2. 下载已有aliyun的数据集
```

unzip OpenCompassData-complete-20240207.zip
cd ./data

```
